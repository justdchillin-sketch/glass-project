# Glassmorphism UI Showcase

A modern glassmorphism-inspired frontend showcase featuring:
- Frosted glass UI effects
- Interactive component library
- Lightbox image gallery
- Dark/light theme toggle
- Responsive layouts and animations

## Tech Stack
- React
- Vite
- Tailwind CSS
- Vanilla JavaScript

### Prerequisites
- Node.js

### Installation
```bash
npm install
```

### Start development server
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

## Deployment
This project is compatible with static hosting.

## Project Structure
- `src/` — React source files
- `script.js` — UI interaction logic
- `style.css` — global styling
- `index.html` — app entry point
